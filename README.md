# Sistema de Gerenciamento de Serviços

Sistema web desenvolvido em Django para gerenciamento de clientes, serviços e agendamentos.

## Funcionalidades

- Login e logout de usuários
- Dashboard com informações do sistema
- Cadastro, edição e exclusão de clientes
- Busca de clientes por nome
- Ativação e desativação de clientes
- Cadastro, edição e exclusão de serviços
- Ativação e desativação de serviços
- Cadastro, edição e exclusão de agendamentos
- Controle de status dos agendamentos
- Controle de chegada dos clientes
- Validação de CPF e telefone
- Formatação de CPF e telefone
- Validação de datas de agendamento
- Impedimento de conflito de horários para o mesmo serviço
- Serviços diferentes podem ser agendados no mesmo horário
- Sistema de mensagens para ações realizadas

## Ferramentas utilizadas

- Python
- Django
- MySQL
- HTML
- CSS
- Bootstrap
- JavaScript
